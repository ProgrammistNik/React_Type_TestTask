# React_Type_TestTask

Простой список задач на React и TypeScript для тестового задания ZalogHub.

## Что умеет приложение

- добавлять задачу через поле ввода и кнопку
- отмечать задачу выполненной и возвращать обратно
- удалять задачу
- фильтровать список: все, активные, выполненные
- сохранять задачи в localStorage

Пустую задачу или задачу из одних пробелов добавить нельзя.

## Запуск

```bash
npm install
npm run dev
```

Сборка:

```bash
npm run build
npm run preview
```

## Время на задание

Около 45 минут.
